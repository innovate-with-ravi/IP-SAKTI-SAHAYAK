# 🚀 Welcome to the IP-SAKTI Sahayak Frontend Repo!

Hey team! I'm super excited to build this SIH project with all of you. Since we have a tight 15-day deadline for the MVP, keeping our code organized from day one will save us from massive headaches and merge conflicts later. 

Here is a quick guide on how we can collaborate smoothly!

## 1. Branching (Keeping things safe)
To make sure we don't accidentally overwrite each other's hard work, our `main` branch is protected. 
*   **Pull first:** Before starting your day, run `git pull origin main` to get everyone's latest updates.
*   **Create a branch:** Please create a new branch for whatever you are working on. 
*   **Naming ideas:** It helps if we label them so we know who is doing what! 
    *   `feature/chat-box`
    *   `bugfix/button-color`
    *   `ui/navbar-design`

## 2. Commits (Leaving breadcrumbs)
Try to commit your work in small chunks. It makes it so much easier to track down bugs later!
*   A helpful commit message explains *what* changed. 
*   *Example of a great commit:* `feat: added the jurisdiction toggle button to the main header`
*   *Try to avoid:* `update` or `fixed stuff` (it makes debugging tough!).

## 3. Writing Code Together
*   **Keep it simple:** We are aiming for a working MVP, so don't stress about making the code overly complex. Simple and clean is perfect.
*   **Comments:** If you write a tricky piece of logic, just drop a quick comment explaining *why* it's there. It helps the rest of us understand your thought process.
*   **Clean up:** Just remember to clear out any temporary `console.log()` tests before finalizing your work.

## 4. Pull Requests (Merging your awesome work)
When your feature or fix is ready, open a Pull Request (PR) to merge it into `main`!
*   **Give a quick summary:** Just write a line or two in the PR description about what you built. Screenshots of new UI components are always awesome to see!
*   **Review:** Assign the PR. We'll give it a quick look to make sure everything links up with our backend properly, and then we'll get it merged in.
